# Contributing to DSK Dassies Decode

Thank you for your interest in contributing to the DSK Dassies FLL robot programs!

## How to Contribute

### Reporting Issues
- Use the GitHub issue tracker to report bugs or suggest features
- Provide detailed descriptions of the issue
- Include the program file name and line number if applicable
- Describe expected vs actual behavior

### Code Contributions

1. **Fork the Repository**
   ```bash
   git fork https://github.com/GearUpZA/DSK_Dassies_Decode.git
   ```

2. **Create a Feature Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**
   - Follow the existing code style
   - Add comments explaining complex movements or logic
   - Test your code on the actual robot when possible

4. **Commit Your Changes**
   ```bash
   git add .
   git commit -m "Add: descriptive commit message"
   ```

5. **Push to Your Fork**
   ```bash
   git push origin feature/your-feature-name
   ```

6. **Submit a Pull Request**
   - Provide a clear description of the changes
   - Reference any related issues
   - Explain how you tested the changes

## Coding Standards

### Python Style
- Follow PEP 8 guidelines where applicable
- Use descriptive variable names
- Add comments for complex robot movements

### Program Structure
- Initialize all motors and sensors at the beginning
- Use the DriveBase for movement when possible
- Include comments for each mission objective
- Set appropriate motor speeds and stopping behaviors

### Testing
- Test all movements on the FLL practice mat
- Verify robot returns to home position
- Check that all attachments work as expected
- Validate timing and accuracy of turns

## Mission Documentation

When adding new mission runs, please include:
- Mission numbers being completed
- Starting position on the mat
- Key objectives and strategy
- Any special setup or calibration notes

## Questions?

Feel free to open an issue for any questions about contributing!

## Code of Conduct

- Be respectful and constructive
- Help others learn and grow
- Focus on what's best for the team and community
- Celebrate successes and learn from failures

Thank you for helping make DSK Dassies better!
